# Huffman Compression Algorithm

A high-performance file compression tool implementing Huffman Coding in C++.

## Features
- 40-60% compression ratio on text files
- Binary file support
- Lossless compression
- Built-in verification system

## Usage
./huffman_compressor

## Technologies
- C++11
- Binary Trees
- Priority Queues (Min-Heap)
- Bit Manipulation
- Binary File I/O
